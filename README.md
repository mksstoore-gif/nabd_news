# نبض الخبر

تطبيق Android شخصي لإنشاء تغريدة خبرية وصورة مرتبطة مباشرة بمحتوى الخبر.

## البناء
يتم إنشاء APK تلقائياً بواسطة GitHub Actions عند كل تحديث على الفرع `main`.

## التحميل
افتح تبويب **Actions** ثم آخر تشغيل ناجح، وستجد ملف **nabd-news-apk** ضمن Artifacts.

> التطبيق يحتاج اتصالاً بالإنترنت لأن توليد النص والصورة يتم عبر خدمة الذكاء الاصطناعي الخاصة بالتطبيق.
