# MoneyPrinter Android Local v2

نسخة محلية بالكامل من واجهة الفيديو:
- لا تحتاج خادم 127.0.0.1.
- نموذج GGUF يعمل على الجهاز عبر llama.cpp.
- نموذج افتراضي مقترح Qwen2.5-0.5B-Instruct Q4_K_M (~400 MB) ويُنزل مرة واحدة.
- تحويل النص إلى كلام عبر محرك Android.
- تركيب الفيديو محلياً عبر FFmpegKit.
- حفظ MP4 مباشرة في Downloads/MoneyPrinter.
- لا حصص يومية أو شهرية يفرضها التطبيق.

ملاحظة: سرعة التوليد تعتمد على RAM/CPU في الهاتف، والصوت العربي يحتاج أن يكون مثبتاً في محرك TTS.
