# MoneyPrinter Turbo Arabic Android

واجهة Android عربية خفيفة لمحرك MoneyPrinterTurbo الأصلي.

- لا يفرض التطبيق حداً يومياً أو شهرياً.
- يتصل بـ MoneyPrinterTurbo API عبر /api/v1.
- يدعم 9:16 و16:9 و1:1.
- يدعم Pexels وPixabay وCoverr حسب إعداد المحرك.
- أصوات عربية سعودية وإماراتية عبر Edge TTS.
- متابعة حالة المهمة وتنزيل MP4 مباشرة.

## التشغيل
شغّل MoneyPrinterTurbo API على نفس الجهاز أو سيرفر خاص، ثم ضع عنوانه داخل التطبيق.
العنوان المحلي الافتراضي: http://127.0.0.1:8080
