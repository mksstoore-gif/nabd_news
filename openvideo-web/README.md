# OpenVideo Web

واجهة عربية مفتوحة المصدر لتحويل النص إلى فيديو حقيقي باستخدام نموذج LTX Video Fast على Hugging Face ZeroGPU.

- لا يحتاج API key من المستخدم.
- لا يفرض التطبيق حصصًا خاصة به.
- يعمل على iPad / iPhone / Android / desktop.
- الكود: MIT.
- نموذج LTX Video وترخيصه منفصلان ويتبعان Lightricks/Hugging Face.

> ملاحظة: موارد ZeroGPU عامة ومشتركة، لذلك قد يوجد طابور أو توقف مؤقت خارج سيطرة هذا التطبيق.
